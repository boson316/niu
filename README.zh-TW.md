## 功能摘要

### v6 — 複利與退休計算機（App）

- **介面：** 手機底部分頁列、結果卡即時更新（不用按「計算」）、捲動時浮動結果列、深色模式、千分位輸入與「≈ 萬」提示
- **複利計算：** 算最終金額／年化報酬率／定期定額／所需本金／所需時間；切換模式時保留上次結果
- **多階段：** 每階段可設投入或領回、頻率、每年調升、期初一次性加碼／提出；自動接續並計算整體 IRR
- **退休規劃：** 4% 法則（提領率可調）＋買房、**通膨調整**、勞保／勞退等其他收入、退休後提領模擬（資產可撐到幾歲）、報酬率 ±2% 情境
- **圖表與明細：** 資產成長圖（可觸控查看數值）、逐年明細表
- **分享與離線：** 分享連結會帶入目前輸入；資料存在瀏覽器；可「加入主畫面」離線使用

**計算方式與 v4／v5 的差異：**

| 項目 | v4／v5 | v6 |
|------|--------|----|
| 年化報酬率 | 名目利率 ÷ 12（月複利 6% 實際約 6.17%） | 預設**有效年化**：月報酬 = (1+r)^(1/12) − 1；進階設定可切回名目 |
| 通膨 | 未考慮 | 退休開銷、房價隨時間成長；顯示「今日購買力」 |
| IRR 求解範圍 | 0.01%～300%（無法算負報酬） | −99%～1000%，掃描＋二分法 |
| 已達成目標 | 顯示「無法達成」 | 正確顯示「已達成」 |
| 投入時點 | 只有期末 | 期末／期初可選，定期金額可每年調升 |
| 提領耗盡 | 餘額變負數 | 標示第幾年資產耗盡 |

### v4 — 年化報酬率計算機

- 算最終金額、IRR、所需本金、所需時間、定期定額
- 多階段：上一階段最終金額可帶入下一階段本金
- v5 可帶參數開啟 v4 細調

### v5 — 退休規劃計算機

- **4% 法則：** 月生活開銷 × 300 = 生活費所需本金
- **買房：** 台北市一次性購屋目標（依近期實價登錄概算預設）
- **退休總目標** = 生活費本金 + 房價
- 反推：幾年能退休、每月要存多少、現在要有多少本金
- 手機：數字鍵盤、底部固定「計算」按鈕
